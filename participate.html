Phases

The validation phase runs on Codabench with result submissions: you upload synthetic CTs and the organizers' scoring program computes the metrics. The test phase will require a Docker container with your method; how and for which teams it is run will be announced later.

Submission format

For the validation phase, upload a single .zip with your synthetic CTs for the tracks you enter. The test-phase submission format will be announced later.

  • One sCT per MRI case, named with the input case ID.
  • Same geometry as the input MRI: size, spacing, origin and direction.
  • Values in Hounsfield Units, stored as compressed NIfTI.

Before you upload

  • Every validation case has an sCT for each track you enter.
  • Geometry matches the input MRI; the scoring program rejects mismatched volumes.
  • No manual editing of the synthetic CTs.
  • Validation and test MRIs are not used to train or adapt the model.
